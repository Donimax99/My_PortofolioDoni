## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/USERNAME/portfolio-react-doni.git
```

Go to the project directory:

```bash
cd portfolio-react-doni
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```
